# 教育成绩管理系统 (EduScore Manager)

一个现代化的教育成绩管理系统，提供直观的成绩录入、统计分析和 AI 智能分析功能，帮助教师更好地管理和分析学生成绩。

## ✨ 功能特点

- 📊 **成绩统计分析**

  - 课程成绩统计概览
  - 分数段分布可视化
  - AI 智能分析报告

- 📝 **成绩管理**

  - 批量成绩录入
  - 单个成绩修改
  - Excel 成绩导出

- 📚 **课程管理**

  - 课程信息维护
  - 学生名单管理
  - 学期管理

- 🎨 **用户体验**
  - 响应式设计
  - 暗色模式支持
  - 流畅的动画效果


## 🚀 快速开始

### 环境要求

- Node.js >= 16
- Python >= 3.9
- MySQL >= 8.0

### 1. 克隆项目

```bash
git clone <repository-url>
cd edu-score-manager
```

### 2. 后端设置

```bash
# 进入后端目录
cd backend
# 安装依赖
pip install -r requirements.txt
# 启动后端服务
python main.py
```

### 3. 前端设置

```bash
# 进入前端目录
cd edu-score-manager
# 安装依赖
npm install
# 启动服务器
npm run dev
```
